Offline usage (no internet)
  1. Download pdf-lib.min.js (UMD build) from the PDF-LIB project and place it next to this index.html.
  2. Uncomment the pdf-lib.min.js script tag in the code (near the bottom) and remove the CDN line if present.
  3. Open this HTML file in Chrome/Edge. Everything runs locally in your browser.
